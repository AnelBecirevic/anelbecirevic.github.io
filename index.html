Featured Project

Java / Spring Boot Web Application

Yu-Gi-Oh! Turbo

Yu-Gi-Oh! Turbo is a learning project built to combine backend development concepts in one larger application. The project includes account management, relational database design, persistent card and deck management, and a simplified browser-based duel prototype.

Java Spring Boot PostgreSQL Spring JDBC Thymeleaf HTML CSS

Key Features

  • User registration and login
  • Password hashing and session management
  • Account management
  • PostgreSQL card database
  • Player card collection / Trunk
  • Persistent 40-card Deck Editor
  • Monster card data and artwork
  • Simplified duel system
  • Tribute Summoning
  • Life Points and battle calculations
  • Basic computer opponent
  • JUnit / Mockito unit tests

04

What I Learned

Database Design

Designing relationships between accounts, cards, card collections and decks helped me understand how relational database structures translate into an actual application.

Layered Architecture

Separating controllers, services and repositories gave me a much clearer understanding of why responsibilities should be divided across different application layers.

Connecting the Pieces

One of the biggest learning steps was moving beyond isolated exercises and connecting database queries, backend logic, sessions and a Thymeleaf frontend in one working application.

05

Development Approach

I developed the project incrementally using GitHub Issues and Git commits to separate larger features into smaller pieces of work.

The project began with the PostgreSQL database and account functionality before expanding into the card collection, deck management and duel prototype.

AI tools were also used as a learning and programming assistant, particularly for debugging, discussing design decisions and accelerating implementation of the duel prototype. I focused on understanding and testing how the generated code integrated with the rest of the application.
