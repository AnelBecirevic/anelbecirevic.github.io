Yu-Gi-Oh! Turbo

Java / Spring Boot Web Application

View Repository →

Yu-Gi-Oh! Turbo is a learning project developed to combine different backend development concepts in one application.

It includes account management, PostgreSQL persistence, card collection and deck management, and a simplified browser-based duel prototype.

Java Spring Boot PostgreSQL Spring JDBC Thymeleaf HTML CSS

Key Engineering Challenges

01
Database Design

Designed a relational PostgreSQL schema for accounts, cards, decks, deck contents and player card collections.

02
Deck & Trunk Management

Implemented logic separating total card ownership from cards currently allocated inside a player's deck.

03
Layered Architecture

Structured the application using Controller, Service and Repository layers to separate HTTP handling, business rules and database access.

04
Account Management

Implemented registration, login, BCrypt password hashing, HTTP session management and protected routes.

05
Duel Prototype

Integrated persistent deck data with a simplified duel system including drawing, summoning, Tribute Summoning, phases, Life Points and a computer opponent.

06
Testing

Added JUnit and Mockito tests for deck-management rules and important duel-service behavior.

This project helped me move from isolated programming exercises to understanding how database design, backend logic and frontend interaction fit together inside a complete application.
