Featured Project

Yu-Gi-Oh! Turbo

Java / Spring Boot Web Application

View Repository

Yu-Gi-Oh! Turbo is a learning project developed to combine different backend development concepts in one application. It includes account management, PostgreSQL persistence, card collection and deck management, and a simplified browser-based duel prototype.

Java Spring Boot PostgreSQL Spring JDBC Thymeleaf HTML CSS

Key Engineering Challenges

  • Database Design: Designed a relational PostgreSQL schema for accounts, cards, decks, deck contents and player card collections.
  • Deck and Trunk Management: Implemented logic that separates total card ownership from cards currently being used inside a player's deck.
  • Layered Architecture: Structured the application using Controller, Service and Repository layers to separate HTTP handling, business logic and database access.
  • Account Management: Implemented registration, login, password hashing, session management and protected routes.
  • Duel Prototype: Integrated persistent deck data with a simplified duel system including drawing cards, summoning, Tribute Summoning, battle phases, Life Points and a basic computer opponent.
  • Testing: Added JUnit and Mockito tests for deck-management rules and core duel-service behavior.
This project helped me move from isolated programming exercises to understanding how database design, backend logic and frontend interaction fit together inside a complete application.
